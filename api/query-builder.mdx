## Overview

The Query Builder provides a chainable API for constructing queries with filtering, relation loading, sorting, pagination and field selection.

Values you pass to `Filter()` are sent to PostgreSQL as bound parameters; they are never written into the SQL text. Field, relation and ordering names are validated against the schema and quoted before they reach the SQL.

## Basic usage

### Query()

Starts a new query for the given entity.

```go
func (e *Engine) Query(entity string) *QueryBuilder
```

**Example:**

```go
result, err := eng.Query("User").Execute(ctx)
if err != nil {
    log.Fatal(err)
}

for _, user := range result.Rows {
    fmt.Printf("User: %s\n", user["name"])
}
```

### Execute()

Executes the query and returns the results.

```go
func (qb *QueryBuilder) Execute(ctx context.Context) (*QueryResult, error)
```

<ParamField path="ctx" type="context.Context" required>
  Context for query execution (supports cancellation and timeouts)
</ParamField>

<ResponseField name="QueryResult" type="*QueryResult">
  Query results containing rows and eager-loaded relations
</ResponseField>

**QueryResult fields:**

<ResponseField name="Entity" type="string">
  Name of the entity queried
</ResponseField>

<ResponseField name="Rows" type="[]Row">
  Main query results (slice of Row maps)
</ResponseField>

<ResponseField name="Relations" type="map[string][]Row">
  Eager-loaded relations (relation name to rows)
</ResponseField>

### ToSQL()

Generates the SQL and its parameters without executing anything.

```go
func (qb *QueryBuilder) ToSQL() (*GeneratedSQL, error)
```

```go
generated, err := eng.Query("User").
    Select("id", "name").
    Filter("email", "eq", "ana@mail.com").
    ToSQL()
if err != nil {
    log.Fatal(err)
}

fmt.Println(generated.MainQuery)  // SQL text with $1, $2, ... placeholders
fmt.Println(generated.MainParams) // the values, kept separate from the SQL
```

`GeneratedSQL` has `MainQuery`, `EagerQueries`, `MainParams` and `EagerParams`.

## Filtering

### Filter()

Adds a filter condition to the query.

```go
func (qb *QueryBuilder) Filter(field string, op string, value interface{}) *QueryBuilder
```

<ParamField path="field" type="string" required>
  A field of the entity (for example `"email"`), or a field of a direct relation (for example `"posts.published"`). Paths deeper than `relation.field` are rejected.
</ParamField>

<ParamField path="op" type="string" required>
  Filter operator: `"eq"`, `"neq"`, `"gt"`, `"gte"`, `"lt"`, `"lte"`, `"like"`
</ParamField>

<ParamField path="value" type="interface{}" required>
  Value to compare against: string, integer, `float64`, `bool` or `nil`
</ParamField>

**Supported operators:**

| Operator | SQL equivalent | Description |
|----------|----------------|-------------|
| `"eq"` | `=` | Equal to |
| `"neq"` | `!=` | Not equal to |
| `"gt"` | `>` | Greater than |
| `"gte"` | `>=` | Greater than or equal |
| `"lt"` | `<` | Less than |
| `"lte"` | `<=` | Less than or equal |
| `"like"` | `LIKE` | Contains (strings only, see below) |

<Warning>
  The `"in"` operator is not supported and is rejected with an error. It will be reintroduced with bound parameters.
</Warning>

**About `like`:**

`like` means "contains". ChameleonDB wraps your value in `%...%` itself and escapes any `%`, `_` or `\` that appears in the value, so they match literally. Do not add wildcards yourself.

```go
// Matches names that contain "Garcia"
eng.Query("User").
    Filter("name", "like", "Garcia").
    Execute(ctx)

// Matches names that contain a literal "100%"
eng.Query("User").
    Filter("name", "like", "100%").
    Execute(ctx)
```

`like` accepts string values only.

**Value types:**

Strings, integers, `float64`, `bool` and `nil` are supported. Other types, such as `time.Time`, are not supported by `Filter()` today (this is a known limitation). Floating-point values are bound as `numeric`, so comparing them with an integer column keeps the exact value.

**Examples:**

```go
// Exact match
eng.Query("User").
    Filter("email", "eq", "ana@mail.com").
    Execute(ctx)

// Numeric comparison
eng.Query("User").
    Filter("age", "gte", 18).
    Execute(ctx)

// Multiple filters (AND logic)
eng.Query("Post").
    Filter("published", "eq", true).
    Filter("views", "gt", 1000).
    Execute(ctx)
// WHERE "published" = $1 AND "views" > $2
```

Unknown fields are rejected before any SQL runs:

```go
_, err := eng.Query("Post").
    Filter("no_such_field", "eq", 1).
    Execute(ctx)
// err mentions: Unknown field 'no_such_field' in entity 'Post'
```

## Field selection

### Select()

Specifies which fields to retrieve (partial selection).

```go
func (qb *QueryBuilder) Select(fields ...string) *QueryBuilder
```

<ParamField path="fields" type="...string" required>
  Field names to select (variadic). Each name is validated against the schema.
</ParamField>

**Behavior:**
- If not called, all fields are selected
- Selected fields are available in `result.Rows`

**Examples:**

```go
users, _ := eng.Query("User").
    Select("id", "name", "email").
    Execute(ctx)

for _, user := range users.Rows {
    // Only id, name and email are available
    fmt.Printf("%s <%s>\n", user["name"], user["email"])
}

// Select with filtering
eng.Query("Post").
    Select("id", "title", "created_at").
    Filter("published", "eq", true).
    Execute(ctx)
// SELECT "id", "title", "created_at" FROM "posts" WHERE "published" = $1
```

## Eager loading

### Include()

Loads related entities with one extra query per relation, instead of one query per parent row.

```go
func (qb *QueryBuilder) Include(path string) *QueryBuilder
```

<ParamField path="path" type="string" required>
  Relation name or nested path (for example `"posts"` or `"posts.comments"`). Each segment is validated against the schema.
</ParamField>

**Behavior:**
- Relations are loaded in separate queries that filter on the parent ids (`WHERE "author_id" = ANY($1)`)
- Results are available in `result.Relations["relation_name"]`
- Supports nested includes with dot notation
- Rows are deduplicated by primary key using an identity map

**Examples:**

```go
// Single relation
result, _ := eng.Query("User").
    Include("posts").
    Execute(ctx)

for _, user := range result.Rows {
    fmt.Printf("User: %s\n", user["name"])
}

if posts, ok := result.Relations["posts"]; ok {
    fmt.Printf("Loaded %d posts\n", len(posts))
    for _, post := range posts {
        fmt.Printf("  - %s\n", post["title"])
    }
}

// Multiple relations
eng.Query("User").
    Include("posts").
    Include("comments").
    Execute(ctx)

// Nested relations: users, their posts, and comments on those posts
eng.Query("User").
    Include("posts.comments").
    Execute(ctx)
```

<Note>
  `result.Relations` holds the related rows of the whole result set for each relation. It is not grouped per parent row.
</Note>

## Sorting

### OrderBy()

Adds a sort clause to the query.

```go
func (qb *QueryBuilder) OrderBy(field string, direction string) *QueryBuilder
```

<ParamField path="field" type="string" required>
  Field name to sort by (validated against the schema)
</ParamField>

<ParamField path="direction" type="string" required>
  Sort direction: `"asc"` or `"desc"`
</ParamField>

**Examples:**

```go
// Ascending
eng.Query("User").
    OrderBy("name", "asc").
    Execute(ctx)

// Descending
eng.Query("Post").
    OrderBy("created_at", "desc").
    Execute(ctx)

// Multiple sort fields
eng.Query("User").
    OrderBy("last_name", "asc").
    OrderBy("first_name", "asc").
    Execute(ctx)
// ORDER BY "last_name" ASC, "first_name" ASC
```

## Pagination

### Limit()

Limits the number of results returned.

```go
func (qb *QueryBuilder) Limit(n uint64) *QueryBuilder
```

<ParamField path="n" type="uint64" required>
  Maximum number of rows to return
</ParamField>

### Offset()

Skips the first N results.

```go
func (qb *QueryBuilder) Offset(n uint64) *QueryBuilder
```

<ParamField path="n" type="uint64" required>
  Number of rows to skip
</ParamField>

**Examples:**

```go
// First 10 users
eng.Query("User").
    Limit(10).
    Execute(ctx)

// Page 2 (rows 11-20)
eng.Query("User").
    Limit(10).
    Offset(10).
    Execute(ctx)

// Pagination helper
func getPage(eng *engine.Engine, page, pageSize int) (*engine.QueryResult, error) {
    offset := (page - 1) * pageSize

    return eng.Query("User").
        OrderBy("created_at", "desc").
        Limit(uint64(pageSize)).
        Offset(uint64(offset)).
        Execute(context.Background())
}
```

## Debug mode

### Debug()

Prints the generated SQL and its parameters for this query.

```go
func (qb *QueryBuilder) Debug() *QueryBuilder
```

**Output:**
- The SQL text, with `$1`, `$2`, ... placeholders
- The parameter values, listed separately
- No timing or row counts (use `DebugTrace()` for those)

**Example:**

```go
result, _ := eng.Query("User").
    Select("id", "name", "email").
    Filter("email", "like", "@example.com").
    Debug().
    Execute(ctx)

// Output:
// [SQL]
// SELECT "id", "name", "email"
// FROM "users"
// WHERE "email" LIKE $1 ESCAPE '\'
//
// [PARAMS]
// $1 = String("%@example.com%")
```

### DebugTrace()

Prints the SQL plus timing and row counts.

```go
func (qb *QueryBuilder) DebugTrace() *QueryBuilder
```

**Example:**

```go
eng.Query("User").
    Select("id", "name").
    DebugTrace().
    Execute(ctx)

// Output (the SQL and the numbers depend on your query and data):
// ┌─────────────────────────────────────
// │ Query Trace
// ├─────────────────────────────────────
// │ SQL:
// │   SELECT ... FROM "users"
// │ Duration: <duration>
// │ Rows: <row count>
// └─────────────────────────────────────
```

<Warning>
  Debug output includes parameter values. Do not enable it where logs can reach people who should not see that data.
</Warning>

## Advanced usage

### Combining features

```go
result, err := eng.Query("Post").
    Select("id", "title", "published", "created_at").
    Filter("published", "eq", true).
    Filter("views", "gte", 100).
    Include("author").
    Include("comments").
    OrderBy("created_at", "desc").
    Limit(20).
    Offset(0).
    Debug().
    Execute(ctx)

if err != nil {
    log.Fatal(err)
}

for _, post := range result.Rows {
    fmt.Printf("Post: %s\n", post["title"])
}

if authors, ok := result.Relations["author"]; ok {
    fmt.Printf("Authors loaded: %d\n", len(authors))
}
if comments, ok := result.Relations["comments"]; ok {
    fmt.Printf("Comments loaded: %d\n", len(comments))
}
```

### Working with results

```go
result, _ := eng.Query("User").Execute(ctx)

// Check if empty
if result.IsEmpty() {
    fmt.Println("No users found")
    return
}

// Count results
fmt.Printf("Found %d users\n", result.Count())

// Iterate rows
for i, user := range result.Rows {
    fmt.Printf("%d. %s <%s> (id: %v)\n", i+1, user["name"], user["email"], user["id"])
}

// Row helpers
firstUser := result.Rows[0]
name := firstUser.String("name")     // "" if not found
age := firstUser.Int("age")          // 0 if not found
value := firstUser.Get("created_at") // interface{}
```

## Query result reference

### QueryResult

```go
type QueryResult struct {
    Entity    string              // "User"
    Rows      []Row               // Main results
    Relations map[string][]Row    // Eager-loaded relations
}
```

**Methods:**

<ResponseField name="Count()" type="int">
  Returns the number of rows in the main result
</ResponseField>

<ResponseField name="IsEmpty()" type="bool">
  Returns true if no rows were returned
</ResponseField>

### Row

```go
type Row map[string]interface{}
```

**Methods:**

<ResponseField name="Get(field)" type="interface{}">
  Returns the raw value of a field
</ResponseField>

<ResponseField name="String(field)" type="string">
  Returns the string value of a field (or "" if not found)
</ResponseField>

<ResponseField name="Int(field)" type="int64">
  Returns the int64 value of a field (or 0 if not found)
</ResponseField>

## Complete example

```go
package main

import (
    "context"
    "fmt"
    "log"
    "os"

    "github.com/chameleon-db/chameleondb/chameleon/pkg/engine"
)

func main() {
    ctx := context.Background()

    eng, err := engine.NewEngine()
    if err != nil {
        log.Fatal(err)
    }
    defer eng.Close()

    config, err := engine.ParseConnectionString(os.Getenv("DATABASE_URL"))
    if err != nil {
        log.Fatal(err)
    }
    if err := eng.Connect(ctx, config); err != nil {
        log.Fatal(err)
    }

    result, err := eng.Query("User").
        Select("id", "name", "email", "created_at").
        Filter("status", "eq", "active").
        Include("posts").
        OrderBy("created_at", "desc").
        Limit(50).
        Execute(ctx)
    if err != nil {
        log.Fatal(err)
    }

    fmt.Printf("Users: %d\n\n", result.Count())

    for _, user := range result.Rows {
        fmt.Printf("User: %s <%s>\n", user["name"], user["email"])
    }

    if posts, ok := result.Relations["posts"]; ok {
        fmt.Printf("Posts loaded: %d\n", len(posts))
    }
}
```
